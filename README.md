# DANA — Character & Experience

DANA의 캐릭터 경험 디자인 포트폴리오.

홈페이지: https://dotoridesuyo.github.io/dana-portfolio/

## 구성

캐릭터 챗봇, 게임 기획, 아트 디렉팅, 사용자 경험 연구와 창작 콘텐츠를 소개합니다.

빌드가 필요 없는 정적 사이트입니다. index.html에 섹션 구성, style.css에 스타일, app.js에 프로젝트 내용과 필터·상세 보기가 있습니다. assets/에는 프로젝트 이미지가 있습니다.

외부 작품 서비스의 로그인과 접근 권한은 해당 서비스 설정을 따릅니다.
