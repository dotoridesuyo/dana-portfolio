# DANA — Design Portfolio

DANA의 디자이너 포트폴리오 홈페이지입니다. HTML과 CSS로 구성된 반응형 정적 사이트입니다.

현재 사이트: https://dana-design-notes.ardentmango128.chatgpt.site/

## 실행

`index.html`을 브라우저에서 열면 됩니다. 설치나 빌드 과정이 필요하지 않습니다.

## 구성

- DANA 소개
- 작업 소개를 위한 예시 그래픽과 준비 중 안내
- 소개 및 연락처 영역
- 모바일 대응 및 섹션 이동 메뉴

작품 그래픽은 구성 예시입니다. 실제 작품과 연락처는 추후 추가할 수 있습니다.

## GitHub Pages

저장소 루트에 `index.html`을 업로드하고 저장소 Settings → Pages에서 배포할 브랜치의 `/ (root)`를 선택하면 됩니다.

## 수정

텍스트와 스타일은 `index.html`에서 수정합니다. 화면의 Work, About, Contact 영역에 실제 프로젝트 이미지, 소개, 연락처를 추가할 수 있습니다.

Google Fonts를 사용하므로 웹폰트 로딩에는 인터넷 연결이 필요합니다. 폰트를 불러오지 못하면 시스템 글꼴로 표시됩니다.
