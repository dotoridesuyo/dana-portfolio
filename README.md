# KIM DANA — Character & Experience

김단아의 캐릭터 경험 디자인 포트폴리오입니다.

홈페이지: https://dotoridesuyo.github.io/dana-portfolio/

## 내용

- 신록의 섬, 리프: 캐릭터 기획과 챗봇, 음악·음성 경험
- 비의 정령 연우: 세계관과 관계 서사 기반 AI 챗봇
- 돌아온 미식가: 순천 AI 게임잼 특별상 수상 팀 프로젝트
- 생성형 AI 캐릭터 비주얼 및 아트 디렉팅
- 캐릭터 챗봇 UI 사용자 경험 연구
- AI를 활용하지 않은 창작 콘텐츠와 캐릭터 작업

## 구성과 수정

빌드가 필요 없는 HTML/CSS/JavaScript 정적 사이트입니다. `index.html`에 소개와 섹션 구성, `style.css`에 스타일, `app.js`에 프로젝트 정보와 필터·상세 보기 동작이 있습니다. `assets/`는 제공된 포트폴리오에서 가져온 작품 이미지와 프로젝트 페이지입니다.

작품 링크는 제공된 포트폴리오에 수록된 주소를 사용합니다. 외부 서비스의 로그인과 파일 공유 권한은 해당 서비스 설정을 따릅니다.

## 로컬 실행

정적 HTTP 서버로 이 폴더를 열면 됩니다. GitHub Pages는 main 브랜치의 루트에서 배포합니다.

작품의 사용·재배포는 저작권자의 허락이 필요합니다.
